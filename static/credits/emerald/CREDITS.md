# Hautes herbes — Pokémon Émeraude

Source : https://github.com/pret/pokeemerald/blob/9103e529c2fbdd7add4a1ff3350c6c1f92112c42/graphics/field_effects/pics/tall_grass.png

Révision : 9103e529c2fbdd7add4a1ff3350c6c1f92112c42

Graphismes d’origine Pokémon Émeraude, GAME FREAK / Nintendo / Creatures. Le dépôt de décompilation pret/pokeemerald ne confère pas de licence sur les graphismes Pokémon.

La planche contient cinq images de 16 × 16 pixels. L’animation d’origine joue les images 1, 2, 3, 4, 0 pendant 10 ticks chacune. Le fichier d’origine et le code descriptif sont conservés ici. Seule la transparence de l’indice de palette 0 est ajoutée pour l’affichage web, sans modifier les couleurs ni les indices des pixels.

La bulle d’exclamation et les signes de sommeil sont dessinés en SVG pour cette application.
